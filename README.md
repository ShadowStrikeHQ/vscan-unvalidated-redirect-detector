# vscan-unvalidated-redirect-detector
Detects potential unvalidated redirect vulnerabilities by analyzing HTML responses for redirect URLs and checking if they are based on user-supplied input. - Focused on Lightweight web application vulnerability scanning focused on identifying common misconfigurations and publicly known vulnerabilities

## Install
`git clone https://github.com/ShadowStrikeHQ/vscan-unvalidated-redirect-detector`

## Usage
`./vscan-unvalidated-redirect-detector [params]`

## Parameters
- `-h`: Show help message and exit
- `--input-param`: No description provided
- `--safe-domains`: No description provided
- `--method`: No description provided
